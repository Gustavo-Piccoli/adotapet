# AdotaPet v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build v1 of AdotaPet, a pet adoption website where shelters (ONGs) publish pets and adopters request adoptions that shelters approve or reject.

**Architecture:** ASP.NET Core (.NET 10) API in Clean Architecture (Domain ← Application ← Infrastructure ← Api, one project each), use cases as interface + implementation with no mediator, errors as domain exceptions mapped to ProblemDetails. Angular 21 standalone SPA with signals and Tailwind in `web/`. SQL Server via EF Core 10. Everything runs with `docker compose`.

**Tech Stack:** .NET 10, ASP.NET Core Identity + JWT bearer, EF Core 10 (SqlServer), Serilog, Scalar, xUnit, Testcontainers.MsSql, Microsoft.AspNetCore.Mvc.Testing; Angular 21 (`@angular/cli@21`), Tailwind CSS v4, angular-eslint 21, Vitest (Angular 21 default runner); Docker Compose, nginx, GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-10-30-adotapet-design.md`

## Global Constraints

- Code, identifiers, DB names and commit messages in English; every user-facing UI string in Brazilian Portuguese (pt-BR). "Shelter" is shown as "ONG" in the UI.
- **Commits never contain AI co-authorship** (`Co-Authored-By` or any other attribution). Conventional-commit style messages (`feat:`, `test:`, `chore:`, `docs:`).
- Nothing copied from PROCERGS/SEFAZ code, names or concepts.
- `net10.0`, `<Nullable>enable</Nullable>`, `<ImplicitUsings>enable</ImplicitUsings>`, `<TreatWarningsAsErrors>true</TreatWarningsAsErrors>` in `Directory.Build.props`.
- Dependency direction enforced by project references: Domain (no NuGet packages) ← Application ← Infrastructure ← Api.
- Feature folders first (`Pets/`, `AdoptionRequests/`, `Shelters/`, `Adopters/`, `Accounts/`, `Common/`), technical aspect as subfolder (`UseCases/`, `Dtos/`, `Persistence/`…).
- Use cases: `I<Name>UseCase` interface + `<Name>UseCase` class in the same file under `<Feature>/UseCases/`, single method `ExecuteAsync(...)`, registered explicitly (Scoped) in `AddApplication()`. Input DTOs are `sealed record`s.
- Paging: `page` ≥ 1 (values < 1 become 1), `pageSize` default 12, clamped to 1..48.
- Photos: JPEG, PNG or WebP only, detected by file signature (not extension), max 5 MB (`5 * 1024 * 1024` bytes), stored under a server-generated GUID file name.
- JWT lifetime 60 minutes, no refresh token. Claims: `sub` (user id), `email`, `role` (`Shelter` | `Adopter`), `profile_id` (Guid of Shelter/Adopter), `name`.
- Access to another shelter's pet or request returns **404**, never 403.
- Ports: API `http://localhost:5080` locally (container port 8080); web dev server `http://localhost:4200` proxying `/api` to 5080; in compose, web on `localhost:4200`, api on `localhost:5080`, SQL Server on `localhost:1433`.
- **Docker is NOT installed on the dev machine yet** (needs reboot). Any step that needs Docker (Testcontainers tests, `docker compose`, running the API against a DB) must still be written and must compile, but its run is marked "deferred until Docker is available" and recorded in `docs/BACKLOG.md` under "Pending verification". Never install Docker/WSL or anything needing admin.
- Shell: Windows with Git Bash. Use `npx @angular/cli@21` (no global install). `dotnet-ef` as a local tool (`dotnet new tool-manifest` + `dotnet tool install dotnet-ef`).

## Review Focus

1. A file renamed to `.jpg` that is not an image (or a 6 MB image) is uploaded as pet photo → 400 with a pt-BR message, nothing written to disk. (Task 4 tests, Task 10 test, Task 14 client-side check)
2. Adopter clicks "Quero adotar" twice / already has a pending request → second attempt returns 409, UI shows "Pedido em análise" instead of a raw error. (Task 5 test, Task 10 test, Task 13 UI test)
3. JWT expires while the SPA is open → next API call returns 401, interceptor clears session and sends user to `/entrar?returnUrl=<current>`. (Task 11 interceptor test)
4. Shelter A opens/edits/decides Shelter B's pet or request by guessing the id → 404. Adopter calling shelter endpoints → 403. (Task 4/5 tests, Task 10 tests)
5. CNPJ typed with mask (`11.222.333/0001-81`) or phone with punctuation → accepted and stored as digits only; invalid CNPJ check digits → 400. (Task 2 tests)
